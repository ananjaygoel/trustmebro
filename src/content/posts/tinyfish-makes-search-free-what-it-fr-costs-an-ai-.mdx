## What's Happening

Here's the thing: An AI agent that reads the web pays 2 kinds of cost.

The first is the retrieval charge: what a search or fetch API bills per request. (we're not making this up)

The second is model processing: content passed from retrieved pages into an AI model consumes tokens, while reasoning and generated responses add further costs.
