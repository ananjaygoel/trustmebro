## What's Happening

So basically Linkup Research has dropped SPARSEUP, an open-source sparse embedding model built on a 149M-parameter ModernBERT backbone.

4 nDCG@10 on BEIR-13, which Linkup calls the best result it knows of for a public sparse encoder under 150M parameters. The model uses a logit shift, top-12 expansion per token and case folding to keep its vectors sparse. (it feels like chaos)

With the Seismic index, it reaches over 97% recall in about 380 microseconds per query, and it ships under Apache 2.
