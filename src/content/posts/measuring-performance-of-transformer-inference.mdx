An LLM service has several kinds of performance.

## The Details

A user cares about how long it takes to see the first token and how quickly the rest of the answer streams. An operator cares about how many requests the hardware can serve, how much memory is used, and how much each generated token costs.

A researcher may care about whether an optimization changes the models output quality. ## Key Takeaways

- Time per output token (TPOT): The average time between generated tokens after the first token.
- Throughput: How many tokens or requests are processed per second.
- Memory usage: How much CPU memory or GPU memory is used.
- Utilization: How busy the accelerator is during the benchmark.

## The Bottom Line

Utilization: How busy the accelerator is during the benchmark. Cost per token: The hardware or service cost divided of tokens processed.
