## What's Happening

Listen up: Exoprimal was built using Capcom’s proprietary RE Engine, which is surprising considering the other Capcom games that have used the engine are quite different.

The first game to publicly use it was Resident Evil 7: Biohazard, which caused many to dub the engine the Resident Evil engine, which is not what the ‘RE’ stands for. (it feels like chaos)

Instead, the acronym is confusingly shorthand for Reach for the Moon.
