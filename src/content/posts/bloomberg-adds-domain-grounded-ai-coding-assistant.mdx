## The Details

Bloomberg’s Chief Technology Officer Shawn Edwards dropped financial professionals are contending with increasingly large and complex datasets, and that turning an investment idea into a repeatable analysis can still demand significant time and specialized coding knowledge. “BQuant Assistant brings AI-driven coding that is informed by Bloomberg’s understanding of financial data and quantitative workflows directly into the workflows our clients already use to build investment strategies,” he dropped.

Edwards dropped the assistant is intended to help every BQuant user — from a portfolio manager drafting an initial query to a quantitative engineer building a multi-asset signal — turn a plain-language question into working code, retrieved data, and a visualization, so clients can more easily test and refine ideas and build investment strategies in BQuant. What BQuant Assistant Does The assistant is integrated within the BQuant development environment, placing conversational AI inside the Python environment where users build investment strategies, dashboards, and quantitative financial analyses.

## Why This Matters

Bloomberg says it can answer users’ questions about BQuant, generate Python code, assist with querying the company’s datasets through Bloomberg Query Language (BQL), help users debug and iterate on their work, and build code for data visualizations.
