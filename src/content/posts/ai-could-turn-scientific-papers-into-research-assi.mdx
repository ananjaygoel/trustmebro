A system called Paper2Agent lets scientists do more than read a new scientific study. When a paper comes with code, methods and data, the system packages these into a tool set that an AI assistant can use to work with new data, researchers report September 16 in Nature .

## Why This Matters

The system is essentially “a virtual author of the paper,” available around the clock, says James Zou, a computer scientist at Stanford University. For our We summarize the week's scientific breakthroughs every Thursday. In tests, Zou and colleagues tried to convert 100 computational biology papers into working tool sets and cooked with 74.

This could have implications for future research in this area.

## Key Takeaways

- The others had obstacles such as missing code or data, or software that wouldn’t run.
- With the papers that were converted, the Paper2Agent tool set could run analyses of the published work and answer questions about the results.
- It did so more accurately and also more than twice as fast as the same agent working from the original papers and accompanying code.

## The Bottom Line

Making another scientist’s code usable can take substantial work, says Peter Clark, a senior research director at the Allen Institute for AI in Seattle who was not involved in developing Paper2Agent. Researchers already code on platforms such as GitHub.
