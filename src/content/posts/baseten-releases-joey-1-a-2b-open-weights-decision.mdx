## Why This Matters

Unlike generative LLMs, a decision model does not generate text. It returns a label and a confidence score for that label in one forward pass, with the scores across all possible answers summing to 1. Given a state — text, optionally with images — and a set of questions, joey-1 returns a calibrated probability for every option from one d-prefix prefill.

The model supports three question types: yes/no, choice among named options, and ordered scoring levels.
