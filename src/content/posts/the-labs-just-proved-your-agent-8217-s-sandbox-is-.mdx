## Why This Matters

A misunderstanding between Anthropic and Irregular, one of the third-party partners it uses for evaluations, left the test machines with live the internet access. The evaluation prompts told the model it had none. So the model had a capture-the-flag task — the standard security drill where you break into a target machine to retrieve a planted secret — a stated constraint that it had no the internet, and an environment that quietly contradicted the constraint.
