## Why This Matters

Add a tenth, and you havent added ten connections, youve potentially added dozens, because now any agent might call any other, and each of those calls can trigger a call somewhere else. Complexity doesnt creep up with agent headcount. It compounds with the number of paths between agents, and nobodys job is to draw that graph.
